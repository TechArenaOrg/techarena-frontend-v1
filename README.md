# TechArena Marketplace v1

A comprehensive, modern e-commerce marketplace built with Next.js 15, TypeScript, and Tailwind CSS.

## ✨ Features

- 🛒 **Complete E-Commerce Suite** - Product catalog, shopping cart, user accounts, order management
- 🎨 **Modern UI/UX** - Beautiful, responsive design with dark/light theme support
- 🔐 **Authentication System** - Secure user registration, login, and profile management
- 📱 **Mobile-First Design** - Fully responsive across all devices
- ⚡ **Performance Optimized** - Fast loading times with Next.js 15 App Router
- 🌍 **Uganda-Focused** - Localized for Ugandan market (UGX currency, local shipping)

## 🛠️ Tech Stack

- **Framework:** Next.js 15.5.2 with App Router
- **Language:** TypeScript 5.6.3
- **Styling:** Tailwind CSS 3.4.14
- **UI Components:** Radix UI primitives
- **Authentication:** NextAuth.js v5
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **State Management:** React Query (TanStack Query)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/cotetech-client-projects/techarena-marketplace-v1.git

# Install dependencies
cd techarena-marketplace-v1
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📋 Pages & Features

- 🏠 **Homepage** - Hero section, featured products, categories
- 🛍️ **Products** - Product catalog with search, filtering, pagination
- 📦 **Product Detail** - Comprehensive product views with reviews
- 🛒 **Shopping Cart** - Add/remove items, quantity management
- 👤 **User Account** - Profile, order history, wishlist
- 🔐 **Authentication** - Login, register, password management
- 📊 **Dashboard** - Admin/vendor analytics and management

│   ├── ui/             # Base UI components

├── lib/                # Utility functions
